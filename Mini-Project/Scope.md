# Mini Project Title
Employee Project Opportunity & Skill Gap Identification
## Project Scope
The Mini Project focuses on developing a focused enhancement to the existing Employee Management System that helps temporarily unallocated employees discover and evaluate upcoming project opportunities. Employees will be able to view available projects, review project descriptions, start dates, and required skills, and compare the requirements with their recorded skills to identify potential skill gaps. Employees can express interest in suitable projects, while Resource Managers can view employees who have expressed interest along with relevant skills and readiness information. The feature will help improve visibility of internal project opportunities and enable the organization to identify suitable existing resources before considering external recruitment for the same requirement. The scope does not include automatic project allocation, recruitment processing, training assignment, or complete workforce management.
